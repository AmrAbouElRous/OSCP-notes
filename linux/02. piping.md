## Reddirecting

![Screenshot](img/02.png)
---
### Standard Output
- `>` redirect but delete old content
- `>>` redirect and append
```bash
echo "Ahmed" > file.txt
echo "mohamed" >> file.txt
```
---
### Standard Input
- `<`
```bash
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ cat < file.txt
Hi

┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ a=file.txt                  
                                                                                                                                                                                                           
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ cat < $a      
Hi

```

### Standard Error
- `2>`
```bash
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ ls -l
total 4
-rw-rw-r-- 1 amro amro 3 Dec 11 20:43 file.txt
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ ls -l > new
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ cat new
total 4
-rw-rw-r-- 1 amro amro 3 Dec 11 20:43 file.txt
-rw-rw-r-- 1 amro amro 0 Dec 11 20:56 new
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ hfgsdjs >> new
hfgsdjs: command not found
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ cat new
total 4
-rw-rw-r-- 1 amro amro 3 Dec 11 20:43 file.txt
-rw-rw-r-- 1 amro amro 0 Dec 11 20:56 new
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ hfgsdjs >> new 2> err            
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ cat err
hfgsdjs: command not found
```
/dev/null is a special device that discards all data written to it, effectively silencing the error messages. it`s Like a **Black Hole**
```bash
sfsfs 2> /dev/null
```

## Piping

![Screenshot](img/02_01.png)

- `cat file.txt | wc`
```bash
amro@amro:~/Desktop/play_ground$ cat file.txt     
Hi
                                                                                                                                                                     
amro@amro:~/Desktop/play_ground$ cat file.txt | wc
      1       1       3
```
- `| tee` is same as `>` but it`s shows you what`s redirected , it helps one the file is large and want to see it in real time
```bash
amro@amro:~/Desktop/play_ground$ ls -l | tee new.txt
total 4
-rw-rw-r-- 1 amro amro 3 Dec 11 20:43 file.txt
                                                                                                                                                                     
amro@amro:~/Desktop/play_ground$ cat new.txt
total 4
-rw-rw-r-- 1 amro amro 3 Dec 11 20:43 file.txt

```
- `| xargs`
```bash
amro@amro:~/Desktop/play_ground$ ls                 
file.txt  new.txt
                                                                                                                                                                     
amro@amro:~/Desktop/play_ground$ ls | xargs rm      
                                                                                                                                                                     
amro@amro:~/Desktop/play_ground$ ls           
                                   
```
