### Standard Output
- `>` redirect but delete old content
- `>>` redirect and append
```bash
echo "Ahmed" > file.txt
echo "mohamed" >> file.txt
```
---
### Standard Input
- `<`
```bash
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ cat < file.txt
Hi

┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ a=file.txt                  
                                                                                                                                                                                                           
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ cat < $a      
Hi

```

### Standard Error
- `2>`
```bash
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ ls -l
total 4
-rw-rw-r-- 1 amro amro 3 Dec 11 20:43 file.txt
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ ls -l > new
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ cat new
total 4
-rw-rw-r-- 1 amro amro 3 Dec 11 20:43 file.txt
-rw-rw-r-- 1 amro amro 0 Dec 11 20:56 new
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ hfgsdjs >> new
hfgsdjs: command not found
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ cat new
total 4
-rw-rw-r-- 1 amro amro 3 Dec 11 20:43 file.txt
-rw-rw-r-- 1 amro amro 0 Dec 11 20:56 new
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ hfgsdjs >> new 2> err            
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/Desktop/play_ground]
└─$ cat err
hfgsdjs: command not found
```
/dev/null is a special device that discards all data written to it, effectively silencing the error messages. it`s Like a **Black Hole**
```bash
sfsfs 2> /dev/null
```
