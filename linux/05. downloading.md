## watch 
The
watch command in Linux runs a specified command repeatedly at regular intervals and displays the output in fullscreen, allowing you to monitor changes in real-time

Common Options
- `-n, --interval <secs>  seconds to wait between updates`
- `-d, --differences[=<permanent>]highlight changes between updates`
```bash
watch date
watch free
watch df
```
► `date` 

► `free` Memory usage

► `df` (short for "disk free") is used to display the amount of available and used disk space on all currently mounted file systems

## Downloading files
### wget
Common options
- `  -P,  --directory-prefix=PREFIX   save files to PREFIX/..`
- `  -O,  --output-document=FILE      write documents to FILE`

- `wget http://192.168.1.7/mutillidae/src/images/coykillericon-50-38.png`

```bash
amro@amro:~$ wget -O p1 http://192.168.1.7/mutillidae/src/images/coykillericon-50-38.png
amro@amro:~$ xdg-open p1

amro@amro:~$ date
Fri Dec 19 02:52:36 PM EET 2025
                                                                                                                                                                                                            
amro@amro:~$ ls -lah p1
-rw-rw-r-- 1 amro amro 2.0K Nov 25 16:52 p1         
```
**Note** Date when u use wget is the date created on the server `Nov 25` not the date of the download it self `Dec 19`
```bash
amro@lab:~$ ls -lah /home/amro/Nakerah-lab-v1/mutillidae/src/images/coykillericon-50-38.png
-rwxr-xr-x 1 root root 2.0K Nov 25 14:46 /home/amro/Nakerah-lab-v1/mutillidae/src/images/coykillericon-50-38.png
```

### axel
Axel
is a lightweight, command-line download accelerator for Linux that speeds up file downloads by using multiple connections to a server for a single file
Common options
- `-n`
- `-o`
```bash
amro@amro:~$ axel -n 6 -o p3 http://192.168.1.7/mutillidae/src/images/coykillericon-50-38.png
amro@amro:~$ ls -lah p3
-rw-rw-r-- 1 amro amro 2.0K Dec 19 17:06 p3
```
**Note** Date with axel is the download date itself `DEC 19`

## zsh History Customization
- `history` shows last commands you executed
Ignore adding some commands to history 

**Note**: zshaddhistory()
is a special hook function in the Zsh shell that is executed just before a command line is saved to the history

► `nano .zshrc` add these
```bash
# Ignore specific commands and patterns in history
zshaddhistory() {
  case "$1" in
    ls*|clear*|history*|exit*|bg*|fg*) return 1 ;;
  esac
  return 0
}
```
Verify it
```zsh
ls 
history | tail
```
- `alias`
```bash
alias l='ls -la'
# now when u type "l" then "ls -la" will execute
```
You can also add it in `.zshrc` to remain permenantly
