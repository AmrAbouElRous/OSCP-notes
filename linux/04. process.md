# Managing Processes
`&` after a command let\`s you peform another command even if the first one didn\`t finish

```bash

└─$ sleep 9000&
[1] 538348
                                                                                                                                                                                                             
└─$ sleep 500& 
[2] 538453
                                                                                                                                                                                                             
└─$ ps aux | grep "sleep"
amro      538348  0.0  0.0   5576  1992 pts/0    SN   14:52   0:00 sleep 9000
amro      538453  0.0  0.0   5576  1860 pts/0    SN   14:53   0:00 sleep 500
amro      538507  0.0  0.0   6528  2216 pts/0    S+   14:53   0:00 grep --color=auto sleep

```

### nohub
Close terminal → process gets SIGHUP → process stops

With nohup:
- SIGHUP is ignored
- Process continues in the background
```bash
┌──(amro㉿amro)-[~]
└─$ jobs
[1]    running    sleep 1000
[2]  - running    sleep 2000
[3]  + running    sleep 3000

┌──(amro㉿amro)-[~]
└─$ nohup sleep 4000& 
[4] 576070
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~]
└─$ nohup: ignoring input and appending output to 'nohup.out'

┌──(amro㉿amro)-[~]
└─$ jobs
[1]    running    sleep 1000
[2]    running    sleep 2000
[3]  - running    sleep 3000
[4]  + running    nohup sleep 4000

# NOW CLOSE TERMINAL 
exit
# Open Terminal Again

┌──(amro㉿amro)-[~]
└─$ jobs
                                                                                                                                                                                                            
┌──(amro㉿amro)-[~]
└─$ ps aux | grep "sleep"
amro      576070  0.0  0.0   5576  1892 ?        SN   16:32   0:00 sleep 4000
amro      577134  0.0  0.0   6528  2188 pts/0    S+   16:34   0:00 grep --color=auto sleep

# Kill the process after finish
┌──(amro㉿amro)-[~]
└─$ kill 576070
                                                                                                                                                                                                            
┌──(amro㉿amro)-[~]
└─$ ps aux | grep "sleep"
amro      582149  0.0  0.0   6528  2264 pts/0    S+   16:44   0:00 grep --color=auto sleep

```

## screen
screen gives you:
- a virtual terminal that stays alive after logout and you can reattach it later
- common commands : `screen` , `screen -ls` , **CTRL + A then D** , `screen -r 644841` , `screen -X -S 644841 quit`
- Steps
1. `screen`
2. put your commands as usual
```bash
amro@amro:~$ sleep 2000& sleep 3000& 
[1] 645292
[2] 645293
                                                                                                                                                                                                          
amro@amro:~$ # CTRL + A then D , This will deattach the screen

amro@amro:~$ screen -ls
There is a screen on:
        644841.pts-1.amro       (12/18/2025 01:32:18 PM)        (Detached)
1 Socket in /run/screen/S-amro.

# Will take u to the screen again 
amro@amro:~$ screen -r 644841 

amro@amro:~$ jobs
[1]  - running    sleep 2000
[2]  + running    sleep 3000

amro@amro:~$ fg %1                   
[1]  - running    sleep 2000
^Z
zsh: suspended  sleep 2000
                                                                                                                                                                                                             
amro@amro:~$ jobs
[1]  + suspended  sleep 2000
[2]  - running    sleep 3000
                                                                                                                                                                                                              
amro@amro:~$ bg %1
[1]  - continued  sleep 2000
                                                                                                                                                                                                              
amro@amro:~$ jobs
[1]  - running    sleep 2000
[2]  + running    sleep 3000

# To terminate the screen 
amro@amro:~$ exit
```
You can either Terminate screen by 
1. `exit` in the screen it self or 
2. `screen -X -S 644841 quit` outside the screen

## Signals in linux 
```bash
amro@amro:~$ kill -l
HUP INT QUIT ILL TRAP IOT BUS FPE KILL USR1 SEGV USR2 PIPE ALRM TERM STKFLT CHLD CONT STOP TSTP TTIN TTOU URG XCPU XFSZ VTALRM PROF WINCH POLL PWR SYS
```
Common Signals
```bash
| Signal    | Number | Meaning                                  |
|----------|--------|------------------------------------------|
| SIGINT   | 2      | Interrupt (Ctrl + C)                     |
| SIGTERM  | 15     | Graceful termination (default `kill`)    |
| SIGKILL  | 9      | Force kill (cannot be caught or ignored) |
| SIGSTOP  | 19     | Stop (pause) a process                   |
| SIGTSTP  | 20     | Terminal stop (Ctrl + Z)                 |
| SIGCONT  | 18     | Continue a stopped process               |
| SIGHUP   | 1      | Hangup (terminal closed)                 |
| SIGSEGV  | 11     | Segmentation fault                       |
| SIGCHLD  | 17     | Child process stopped/exited             |

```
