# Practical Tools
## netcat
- `netstat -nl` to show open ports
Target machine
```zsh
# ssh amro@192.168.1.7
amro@lab:~$ nc -nlv 4444
Listening on [0.0.0.0] (family 0, port 4444)
Connection from 192.168.1.5 42128 received!
hi
hi bro
```
attacker
```zsh
┌──(amro㉿amro)-[~]
└─$ nc -v 192.168.1.7 4444
192.168.1.7: inverse host lookup failed: Unknown host
(UNKNOWN) [192.168.1.7] 4444 (?) open
hi
hi bro
```
