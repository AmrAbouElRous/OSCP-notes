Permenant PATH editing inside `.zshrc`
```
┌──(amro㉿amro)-[~/custom_commands]
└─$ echo 'export PATH=/home/amro/custom_commands:$PATH' >> ~/.zshrc
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/custom_commands]
└─$ source ~/.zshrc
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/custom_commands]
└─$ echo $PATH                                                     
/home/amro/custom_commands:/home/amro/.local/bin:/usr/local/sbin:/usr/sbin:/sbin:/usr/local/bin:/usr/bin:/bin:/usr/local/games:/usr/games:/snap/bin:/home/amro/.dotnet/tools
                                                                                                                                                                                                             
┌──(amro㉿amro)-[~/custom_commands]
└─$ say_hello      
hello

# BONUS ! : There`s a vulnearbility here try to detect and solve it ?
# /home/amro/custom_commands:/home/amro/.local/bin:/usr/local/sbin:/usr/sbin:/sbin:/usr/local/bin:/usr/bin:/bin:/usr/local/games:/usr/games:/snap/bin:/home/amro/.dotnet/tools
# custom_commands comes before others so u might harm you system if u modified something critical like sudo command
# so it`s better to put this directory at the end because linux always obey what comes first in the PATH
# /home/amro/.local/bin:/usr/local/sbin:/usr/sbin:/sbin:/usr/local/bin:/usr/bin:/bin:/usr/local/games:/usr/games:/snap/bin:/home/amro/.dotnet/tools:/home/amro/custom_commands
```
- Now executables inside `/home/amro/custom_commands` will be accessed directly

### Bash History
- `history` , to run any previous command get it\`s number `!2004` , `!!` is for last command
```
┌──(amro㉿amro)-[~]
└─$ history
 1998  nano
 2000  exit
 2002  ./ls
 2003  rm ls
 2004  ls
 
┌──(amro㉿amro)-[~]
└─$ !2004              
                                                                                                                                                                                                            
┌──(amro㉿amro)-[~]
└─$ ls
```
