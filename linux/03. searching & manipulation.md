# sed (Stream Editor)
- edit in real time
- [📄 sed ](./%285%29%20sed_cheat_sheet.md)
- `cat s.text | sed 's/password/admin/'`
- `sed 's/password/admin/' s.text`
- `sed 's/password/admin/' s.text > new.txt`
```bash
┌──(amro㉿amro)-[~/Desktop/play]
└─$ cat s.text
password
PASSWORD
PASSWORDS
passWorD

# Note this will not edit the original file
┌──(amro㉿amro)-[~/Desktop/play]
└─$ sed 's/password/admin/' s.text
admin
PASSWORD
PASSWORDS
passWorD

┌──(amro㉿amro)-[~/Desktop/play]
└─$ sed 's/password/admin/' s.text > new.txt
                                                                                                                                                                                                              
┌──(amro㉿amro)-[~/Desktop/play]
└─$ cat new.txt
admin
PASSWORD
PASSWORDS
passWorD

```
