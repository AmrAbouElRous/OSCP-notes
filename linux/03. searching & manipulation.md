# sed (Stream Editor)
- edit in real time
- [📄 sed ](./%285%29%20sed_cheat_sheet.md)
- `cat s.text | sed 's/password/admin/'`
- `sed 's/password/admin/' s.text`
- `sed 's/password/admin/' s.text > new.txt`
```bash
┌──(amro㉿amro)-[~/Desktop/play]
└─$ cat s.text
password
PASSWORD
PASSWORDS
passWorD

# Note this will not edit the original file
┌──(amro㉿amro)-[~/Desktop/play]
└─$ sed 's/password/admin/' s.text
admin
PASSWORD
PASSWORDS
passWorD

┌──(amro㉿amro)-[~/Desktop/play]
└─$ sed 's/password/admin/' s.text > new.txt
                                                                                                                                                                                                              
┌──(amro㉿amro)-[~/Desktop/play]
└─$ cat new.txt
admin
PASSWORD
PASSWORDS
passWorD

```

### cut
- `cut`
```bash
-c (characters): Selects characters at specific positions.
-f (fields): Selects fields delimited by a specific character (e.g., columns in a CSV file).
-b (bytes): Similar to -c, used for bytes (less common for standard text). 
-d 
```

### awk
- Basic Syntzx of awk
- `awk 'pattern { action }' input_file`
```bash
$0: Represents the entire line (record).
$1, $2, ...: Represent the first, second, and subsequent fields (columns).
Default Delimiter: Whitespace (spaces or tabs) is the default field separator.
-F option: Used to specify a custom input field separator, like a comma for CSV files. 
```
EXAMPLE
```bash
┌──(amro㉿amro)-[~/Desktop/play]
└─$ cat employees.txt                   
ID|Name|Department|Salary
101|Alice Smith|Sales|60000
102|Bob Johnson|IT|75000
103|Charlie Williams|Sales|62000
104|Diana Brown|IT|80000
105|Eve Davis|HR|55000
106|Frank Miller|IT|71000
```
- `cat employees.txt | awk '{print}'`
- `cat employees.txt | awk '{print $1,$3}'`
```bash
┌──(amro㉿amro)-[~/Desktop/play]
└─$ cat employees.txt | awk '{print $1,$3}' 
ID|Name|Department|Salary 
101|Alice 
102|Bob 
103|Charlie 
104|Diana 
105|Eve 
106|Frank 
```
- `cat employees.txt | awk -F\| '{print $1,$3}'` specify `|` as the sperator
```bash
┌──(amro㉿amro)-[~/Desktop/play]
└─$ cat employees.txt | awk -F\| '{print $1,$3}'
ID Department
101 Sales
102 IT
103 Sales
104 IT
105 HR
106 IT
```
- `cat employees.txt | awk '/IT/ {print}'`
```bash
┌──(amro㉿amro)-[~/Desktop/play]
└─$ cat employees.txt | awk '/IT/ {print}'
102|Bob Johnson|IT|75000
104|Diana Brown|IT|80000
106|Frank Miller|IT|71000
```
- `cat employees.txt | awk -F\| '$1 > 102 {print $1,$2}'`
```bash
┌──(amro㉿amro)-[~/Desktop/play]
└─$ cat employees.txt | awk -F\| '$1 > 102 {print $1,$2}'
ID Name
103 Charlie Williams
104 Diana Brown

```
- `awk -F\| '{if ($3~/IT/) print}'`
