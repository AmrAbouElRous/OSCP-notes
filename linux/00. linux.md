### Which tool does this ? 
- Which tools are used for cracking ?
- `apropos crack` will list u all tools that can crack something like passwords
```bash
┌──(root㉿amro)-[~]
└─# apropos crack
ophcrack (1)         - a Microsoft Windows password cracker using rainbow tables.
aircrack-ng (1)      - a 802.11 WEP / WPA-PSK key cracker
airodump-ng (8)      - a wireless packet capture tool for aircrack-ng
airtun-ng (8)        - a virtual tunnel interface creator for aircrack-ng
besside-ng (8)       - crack a WEP or WPA key without user intervention and collaborate with WPA cracking statistics
cracklib-check (8)   - Check passwords using libcrack2
cracklib-format (8)  - cracklib dictionary utilities
cracklib-packer (8)  - cracklib dictionary utilities
cracklib-unpacker (8) - cracklib dictionary utilities
create-cracklib-dict (8) - Check passwords using libcrack2
hydra (1)            - a very fast network logon cracker which supports many different services
ncrack (1)           - Network authentication cracking tool
ophcrack-cli (1)     - a Microsoft Windows password cracker using rainbow tables.
psk-crack (1)        - Crack IKE Aggressive Mode Pre-Shared Keys
reaver (1)           - WPS Cracker
update-cracklib (8)  - Regenerate cracklib dictionary
wesside-ng (8)       - crack a WEP key of an open network without user intervention
wifite (1)           - Python script to automate wireless auditing using aircrack-ng tools
```
