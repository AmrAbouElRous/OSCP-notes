### Linux Services
- HTTP service
- SSH service

All services are inside `ls /usr/lib/systemd/system | grep ".service"`

```bash
┌──(amro㉿amro)-[/usr/lib/systemd/system]
└─$ ls /usr/lib/systemd/system | grep "ssh.service"
ssh.service
# You can use find as well
# find /usr/lib -name "*.service"
```

## Installing and Removing tools
- `apt update`
- `apt upgrade`
- `apt-cache search apache2`
- `apt show apache2`
- `apt install apache2`
- `apt remove apache2` to remove configuration too `--purge`
- ✅ Installing .deb Files (Manual Packages)
```bash
wgethttps://dl.google.com/linux/direct/google-chrome-stable_current_amd64.deb
dpkg -i google-chrome-stable_current_amd64.deb
# To fix dependancies
sudo apt --fix-broken install
```
