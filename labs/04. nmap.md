#### A TCP connect scan (-sT) in Nmap completes a full TCP three-way handshake to determine if a port is open
```bash
┌──(amro㉿amro)-[~]
└─$ nmap 192.168.1.4 -p 25 -sT
```

#### Nmap TCP SYN scan (-sS) Called Stealth scan ,is a popular port scanning technique that does not complete the full TCP three-way handshake, making it less likely to be logged by target applications and some firewalls. This method is the default TCP scan type when Nmap is run with root privileges
```bash
┌──(amro㉿amro)-[~]
└─$ sudo nmap 192.168.1.4 -p 25 -sS
```
```bash
NO	Time		Source		Destination  Prtotocol Length	Info
8	2.808659866	192.168.1.5	192.168.1.4	TCP	58	58242 → 25 [SYN] Seq=0 Win=1024 Len=0 MSS=1460
9	2.808807436	192.168.1.4	192.168.1.5	TCP	60	25 → 58242 [SYN, ACK] Seq=0 Ack=1 Win=5840 Len=0 MSS=1460
10	2.808829386	192.168.1.5	192.168.1.4	TCP	54	58242 → 25 [RST] Seq=1 Win=0 Len=0
```

- Scan types Notes
- -sT complete TCP scan 3 ways hanshake     (SYN,SYN/ACK,ACK)
- -sS stealth desn`t send the final ACK     (SYN,SYN/ACK)
