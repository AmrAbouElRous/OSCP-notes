## Nmap NSE Scripts
### dns-zone-transfer.nse

- A **zone** = a file that contains ALL DNS records of a domain (A records , MX records , CNAME , TXT , Subdomains , Internal hostnames).
- A **DNS Zone Transfer (AXFR)** is a process where secondary DNS servers copy the entire DNS zone file from the primary server to stay synchronized.
- **DNS Zone Transfer (AXFR)** a dangerous misconfiguration that leaks all DNS records of a domain.
- **A DNS Zone Transfer (AXFR)** is a process where one DNS server copies the entire DNS database (all records and subdomains) from another DNS server, and if allowed to anyone on the internet it becomes a dangerous misconfiguration because it exposes all internal DNS information.

`nmap --script=dns-zone-transfer.nse megacorpone.com -p 53` it be filtered `53/tcp filtered domain`

### masscan
- Masscan is an extremely fast, open-source TCP port scanner designed for Internet-scale network reconnaissance. It works by using asynchronous transmission to send millions of packets per second, allowing it to scan large parts of the internet in minutes. Its primary use is for security auditing, mapping large networks, and identifying exposed services quickly, but it is less detailed than traditional scanners like Nmap for in-depth analysis of a single hos

- 🎉 Short summary

- the ideal approach is to use Masscan first for a fast overview of open ports, then run Nmap on the results for accurate, detailed scanning
