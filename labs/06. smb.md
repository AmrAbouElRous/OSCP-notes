# SMB Enumeration Notes

## SMB & NetBIOS Ports
- **SMB:** TCP **445**
- **NetBIOS:** UDP **137**, UDP **138**, TCP **139**

---

## SMB Setup (Microsoft Server 2012)
### **Prerequisites (Install SMB Server Components)**
1. Add Roles and Features
2. Server Roles → **File and Storage Services**
3. File and iSCSI Services → **File Server Resource Manager**

### **Share a Folder**
1. Right‑click folder → Properties
2. **Sharing** → Advanced Sharing → Add permissions you want
3. **Security** → Add → type **Everyone** → choose permissions

### **SMB Misconfiguration Vulnerability**
Control Panel → Network and Internet → Network and Sharing Center → Change advanced sharing settings → All Networks → **Turn off password‑protected sharing**

```bash
smbclient //192.168.1.6/test
```

## Useful Nmap Arguments
```bash
Some useful arguments for nmap 
   -p <port ranges>: Only scan specified ports
     Ex: -p22; -p1-65535; -p U:53,111,137,T:21-25,80,139,8080,S:9
     
   -sV: Probe open ports to determine service/version info

  --script=<Lua scripts>: <Lua scripts> is a comma separated list of
           directories, script-files or script-categories
   --script-args=<n1=v1,[n2=v2,...]>: provide arguments to scripts
  --script-args-file=filename: provide NSE script args in a file
  --script-updatedb: Update the script database.
  --script-help=<Lua scripts>: Show help about scripts.
           <Lua scripts> is a comma-separated list of script-files or
           script-categories.
```
