# Cross-Site Scripting XSS
- Cross-Site Scripting (XSS) is a web vulnerability where poor input validation allows an attacker to inject malicious JavaScript—either reflected through a crafted URL to target a specific victim or stored in places like comments to affect all visitors—potentially enabling cookie theft or other harmful actions.
- Main Types
1. Reflected XSS – Payload comes from the URL and reflects immediately in the response.
2. Stored XSS – Payload is saved on the server (e.g., comments) and affects every visitor.
3. DOM-based XSS – Vulnerability is in the browser-side JavaScript.
