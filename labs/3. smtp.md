## Python Script #1 — Single User Enumeration
```python
#!/usr/bin/python3
import socket
import sys

print("Usage: ./custom_enum.py <IP> <USER> \r\n")

ip = sys.argv[1]
user = sys.argv[2]
port = 25

# Create a TCP/IP socket
s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
s.connect((ip, port))

# Receive banner
print(s.recv(1024).decode())

# Send VRFY command
payload = f"VRFY {user}\r\n"
s.send(payload.encode())

# Receive response
print(s.recv(1024).decode())

s.close()
```

## Python Script #2 — Enumerate via Wordlist
```python
#!/usr/bin/python3
import socket
import sys

print("Usage: ./custom_enum.py <IP> <WORDLIST>\n")

ip = sys.argv[1]
wordlist = sys.argv[2]
port = 25

with open(wordlist, "r") as f:
    users = [line.strip() for line in f]

for user in users:
    s = socket.socket(socket.AF_INET, socket.SOCK_STREAM)
    s.connect((ip, port))

    s.recv(1024)

    payload = f"VRFY {user}\r\n"
    s.send(payload.encode())

    response = s.recv(1024).decode()

    print(f"[+] {user} --> {response.strip()}")

    s.close()
```

## What is an Open Relay Attack?
An **Open Relay** is a misconfigured SMTP server that allows *anyone* to send email to *any destination* without authentication. Attackers exploit this to send spam or spoofed emails.
