# NFS Enumeration Notes

## Target Setup
- **Microsoft Server 2012** → `192.168.1.6`
- **Metasploitable 2** → `192.168.1.6`
- **Kali (Attacker)** → `192.168.1.5`
- **NAT Network** → `192.168.1.0/24`

---

## What is NFS Enumeration?
NFS (Network File System) allows systems to share directories over a network. Enumerating NFS helps identify:
- Exposed shared folders
- Misconfigured permissions
- Potential data leaks
- Root access allowed to remote machines

Common NFS-related ports:
- **TCP 111** (RPCbind)
- **TCP 2049** (NFS)

---

## Enable NFS on Windows Server 2012

### 1. Install NFS Feature
1. Open **Server Manager**.
2. Click **Manage → Add Roles and Features**.
3. Continue until **Server Roles**.
4. Expand **File and Storage Services**.
5. Under **File and iSCSI Services**, check **Server for NFS**.
6. Click **Install**.

### 2. Start NFS Service
1. Press **Win + R** → type `services.msc`.
2. Find **Server for NFS**.
3. Start the service.
4. Optional: Set **Startup type → Automatic**.

## Kali Enumeration Commands

### Check if NFS port is open
```bash
nmap -p 2049 192.168.1.6
```

### List RPC services
```bash
rpcinfo -p 192.168.1.6
```

### View showmount help
```bash
showmount --help
```

### Check exported shares
```bash
showmount --exports 192.168.1.6
```

---

## Creating and Sharing a Folder (Windows Server 2012)
1. Create a folder.
2. Right‑click → **Properties**.
3. Go to **NFS Sharing**.
4. Click **Manage NFS Sharing**.
5. Enable **Share this folder**.
6. Configure permissions (optional):
   - Allow root access
   - Read/Write

---

## After Sharing the Folder
Check shares again:
```bash
showmount -e 192.168.1.6
```
Example output:
```
/gg (everyone)
```

---

## Mounting NFS Share on Kali
### Start rpcbind
```bash
sudo service rpcbind start
```

### Create a mount directory
```bash
sudo mkdir /mnt/share_nfs
```

### Mount the share
```bash
sudo mount -t nfs 192.168.1.6:/ /mnt/share_nfs
```

### Check files
```bash
ls /mnt/share_nfs
```
Expected structure:
```
gg
```

### Enter the shared folder
```bash
cd /mnt/share_nfs/gg
ls
```
Example file:
```
helpMe.txt
```

### Read the file
```bash
cat helpMe.txt
```
