## 1. Service discovery (Nmap)

Scan SMB ports and collect service/version data and useful SMB scripts in a single command:

```bash
nmap -v -sV -p 139,445 --script=smb-os-discovery,smb-enum-shares,smb-enum-users,smb-vuln-ms17-010 -Pn -oA results/smb 192.168.1.4
```

**Notes:**

- `-sV` attempts version detection.
- `-Pn` skips host discovery (handy in lab environments).
- `--script=` runs SMB-related NSE scripts (adjust list as needed).
- `-oA` saves output in three formats (`.nmap`, `.gnmap`, `.xml`).
- `cd /usr/share/nmap/scripts && ls | grep "smb"` scripts location



## 2. Basic share enumeration

```bash
# List shares (anonymous/null session)
smbclient -L //192.168.1.4 -N

# Connect to a specific share (example: tmp) and interactively list/download
smbclient //192.168.1.4/tmp -N

# enum4linux quick scan (shows users, shares, OS, policies)
enum4linux 192.168.1.4

# Or run the aggressive option for full output
enum4linux -a 192.168.1.4
```

**Tips:**

- `-N` tells `smbclient` to use a null (no) password.
- `smbclient` can accept credentials: `-U 'username%password'`.
- Use `smbclient` non-interactively: `smbclient //IP/share -N -c 'ls;get secretdoc.txt;exit'`.

## 3. RPC / Null session enumeration (`rpcclient`)

## Null Sessions — quick explanation

**Null sessions** are unauthenticated SMB/RPC connections that older Windows/Samba setups allowed. They can leak user lists, share info, and other metadata. On Metasploitable2, null sessions are normally allowed and useful for initial enumeration.

**Detection:** `rpcclient -U "" ip -c "enumdomusers"` or `smbclient -L //ip -N` succeeding indicates a null session.

**Mitigation (for defenders):** disable anonymous SMB access, enforce SMB signing, upgrade SMB implementations, and patch old vulnerabilities.



Check whether null sessions are allowed and enumerate domain users, shares, printers, etc.

```bash
# Start rpcclient with an empty user (null session)
rpcclient -U "" 192.168.1.4
# Then inside rpcclient prompt, try commands like:
# enumdomusers, enumdomgroups, enumalsgroups, enumprinters, lookupnames, srvinfo
# Example (single-line execution):
rpcclient -U "" 192.168.1.4 -c "enumdomusers"
```

- Useful `rpcclient` commands: `enumdomusers`, `enumdomgroups`, `enumprinters`, `lookupnames`, `srvinfo`, `enumshares`.

## 4. Mounting shares (local retrieval)

If you want to mount a share to copy many files:

```bash
# Example: mount as guest (adjust 'vers=' if needed: 1.0, 2.0, 3.0)
sudo mkdir -p /mnt/smb_tmp
sudo mount -t cifs //192.168.1.4/tmp /mnt/smb_tmp -o guest,vers=1.0
#-t cifs: This option tells the mount command to treat the specified source (//192.168.1.4/tmp) as #a CIFS (Common Internet File System) filesystem. CIFS is the standard Linux/Unix implementation #of the SMB (Server Message Block) protocol used for Windows file sharing
# Then inspect /mnt/smb_tmp with regular file tools
ls -la /mnt/smb_tmp
```

**Caveats:** specify `vers=` if mount fails. Some old targets require `vers=1.0` (SMBv1).

```bash
# 
sudo umount /mnt/smb_tmp
```
