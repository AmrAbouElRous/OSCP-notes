# Install Nessus (Manual .deb Installation)
Download the Nessus Debian package:
- Go to **tenable.com → Products → Nessus → Download**
- Choose the Linux Debian package, e.g.: `Nessus-10.x.x-debian10_amd64.deb`

```bash
┌──(amro㉿amro)-[~/Downloads]
└─$ sudo apt install ./Nessus-10.10.1-debian10_amd64.deb
```

After installation:
- Start Nessus:
```bash
/bin/systemctl start nessusd.service
```
- Configure in browser:
```
# https://NESSUS_HOSTNAME_OR_IP:8834/
https://192.168.1.5:8834/

```

# Nessus Systemd Commands

/etc/init.d/nessusd **does NOT exist** in new versions , Nessus now uses a **systemd service**:
```
/lib/systemd/system/nessusd.service
```

```bash
sudo systemctl start nessusd
sudo systemctl stop nessusd
sudo systemctl status nessusd
or
sudo /bin/systemctl start nessusd.service
sudo /bin/systemctl stop nessusd.service
sudo /bin/systemctl status nessusd.service
```
Remember to stop nessusd.service when u don`t use it because it consumes much resources

# Run All Scripts in the "vuln" Category
⚠️ **Very aggressive scan**
```bash
# some scripts require -sV to know service version 
# Avoid false positives : Without -sV, Nmap may not know exactly what service is on the port → scripts could run blindly → inaccurate results.
┌──(amro㉿amro)-[~]
└─$ nmap -v 192.168.1.4 -sV --script vuln
```
