## 🧩 Overview: What is SNMP?

**SNMP (Simple Network Management Protocol)** — UDP port **161** — is a standard Internet protocol used to monitor and manage devices on IP networks such as routers, switches, and servers.  
It allows a **central system (SNMP manager)** to collect information from **SNMP agents** installed on target systems.

This helps administrators:
- Track performance  
- Identify issues  
- Configure devices remotely

## ⚙️ Step 1: Setup SNMP on Microsoft Server 2012

### 1. Install SNMP Feature

1. **Open Server Manager**
   - Click **Start → Server Manager**

2. **Add Roles and Features**
   - Click **“Add roles and features”**

3. **Select Installation Type**
   - Choose **“Role-based or feature-based installation”**
   - Click **Next**

4. **Select Destination Server**
   - Pick your Windows Server instance  
   - Click **Next**

5. **Select Features**
   - Scroll down and check **“SNMP Service”**
   - Click **Add Features** if prompted  
   - Click **Next → Install**

---

### 2. Configure SNMP Service

1. **Open Services**
   - Press `Win + R` → type `services.msc` → press Enter

2. **Locate SNMP Service**
   - Find **“SNMP Service”** in the list

3. **Open Properties**
   - Right-click → **Properties** → go to **Security tab**

4. **Add Community String**
   - Click **Add** under “Accepted community names”
   - Enter a name (e.g., `public`)
   - Set **community rights** → *READ ONLY*

5. **Configure Accepted Hosts**
   - Under “Accept SNMP packets from these hosts” → click **Add**
   - Enter **Kali Linux IP** (your attacker VM IP) or any host

6. **Apply & Start SNMP**
   - Click **OK**
   - Back in Services, right-click **SNMP Service** → **Start**
